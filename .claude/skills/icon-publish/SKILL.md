# icon-publish

自动执行图标库的完整发布流程，包括同步、构建、版本升级和发布。

## 触发词

- "更新图标库"
- "发布图标"
- "publish icons"
- "release icons"

## 功能

执行以下自动化流程：
1. 同步 SVG 图标文件
2. 自动升级版本号（patch）
3. 构建 React 图标库
4. 发布到 npm
5. 提交 git 变更

## 使用方式

```
/icon-publish
```

或直接说"更新图标库"
